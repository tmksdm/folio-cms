## Текущий результат

Адаптивная админка сохранена: обзор, пустые сайты, доступ. Реализован вход по шестизначному email-коду через Resend, серверная проверка Turnstile, атомарные ограничения отправок и попыток, одноразовость, защищённая cookie-сессия на час и выход с отзывом серверного токена. Все ресурсы админки/API требуют сессии; публичны только вход и необходимые ресурсы/API авторизации. Без конфигурации Worker возвращает 503.

По доработке `01.txt`: страница входа больше не спрашивает email — форма содержит только Turnstile (`data-size="normal"`, примерно 300×65 px) и кнопку «Получить код»; получателя сервер берёт из ALLOWED_EMAIL, email из браузера не принимается и не показывается на публичных страницах. Сравнение введённого адреса с разрешённым удалено. На экранах уже 360 px виджет масштабируется (`zoom: .85`) и не создаёт горизонтальной прокрутки. Следствие: письмо уходит на ALLOWED_EMAIL при каждом запросе, прошедшем Turnstile, поэтому любой такой запрос расходует общую квоту отправок; пер-IP лимиты и Turnstile остаются щитом от массового расхода.

Один SQLite Durable Object хранит только состояние авторизации. Коды — HMAC, nonce/сессии/IP — хеши; проверки и изменение состояния выполняются в transactionSync. Workers KV не используется. Migration `v1-auth` / `new_sqlite_classes` включена в Wrangler. Поддержка SQLite DO на Workers Free проверена по официальной документации; оплачиваемые тарифы не включались.

Разрешённый email задаётся через серверный ALLOWED_EMAIL, ключ отправки — RESEND_API_KEY. По уточнению пользователя почта нового аккаунта Resend может отличаться от GitHub; значения email и API-ключ должны относиться к одному аккаунту Resend. Смена email через админку отложена по выбору пользователя: без своего домена `onboarding@resend.dev` отправляет только владельцу Resend. Новых сайтов, редактора и GitHub API нет.

Документы PRODUCT/ARCHITECTURE/ROADMAP/README/AGENTS/DEPLOY обновлены под собственный вход. Производственная зависимость jose удалена; Miniflare закреплён как devDependency для runtime-тестов (та же версия, которую использует Wrangler). Реальных секретов/адреса владельца в Git нет, тестовые подмены находятся исключительно в tests/.

## Ограничения и следующий результат

Опубликованный Worker на Cloudflare работает (владелец подтвердил вход по коду, Turnstile и Resend на реальном домене), но доработка `01.txt` ещё не развёрнута: после внешнего ревью владелец повторяет deploy по DEPLOY.md и приёмку по его списку (вход без поля email, виджет normal). Нет доступа к production-настройкам Cloudflare/Resend; секреты не запрашивались.

Лимиты не гарантируют доступность при DDoS/исчерпании Free-квот; лимит IP-счётчиков может временно отказать новым IP. Любой прошедший Turnstile посетитель расходует общую квоту отправок на ALLOWED_EMAIL; виджет normal в тестовом режиме шире прежнего, в production-режиме отображается без тестовой плашки. На Free требуется следить за usage, платный план не включать автоматически. Resend без домена ограничен одним адресом своего аккаунта.
