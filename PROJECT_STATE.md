## Проверки и ограничения

Проверено 2026-10-11 на Windows, Node 24.14.0/npm 11.9.0:

- `npm.cmd ci`: чистая установка lockfile успешна; audit на момент установки — 0 vulnerabilities.
- `npm.cmd run check`, `npm.cmd test`: JavaScript корректен; 15/15 тестов. Включены настоящие RSA-подписи, неверные issuer/audience/email, срок, поддельные JWT, отсутствие настроек, защищённые страницы/ресурсы/API, отказ при проблемах JWKS.
- `npm.cmd run build`: dry-run Worker успешен; без платных bindings. Bundle около 59 KiB (gzip около 16 KiB).
- `npx.cmd wrangler dev --ip 127.0.0.1 --port 8787`: настоящий локальный runtime отдаёт 503 без конфигурации на HTML, API, JavaScript и неизвестный маршрут.
- Edge, `playwright-cli run-code --filename tests/browser-check.js`: 1440/390/320 px, нет горизонтальной прокрутки, навигация, прямые страницы и reload, клавиатура, загрузка, 503/retry, offline/retry, 403/повторный вход. Нет необработанных ошибок страницы. PNG в локальном `output/playwright/` осмотрены; тестовый signer не является Cloudflare Access.

Зависимости закреплены в lockfile: jose (MIT), Wrangler и Playwright CLI (Apache-2.0). GitHub Actions запускает install/check/test/build без deploy и Cloudflare secrets; статус удалённого run проверяется отдельно при публикации.

**Блокер реальной приёмки:** Cloudflare не развёрнут, нет авторизованного доступа к аккаунту владельца в этой работе. Доставка OTP, policy, logout и CPU-квота Free на опубликованном Worker не проверены. Нужны действия владельца по `DEPLOY.md`. Не считать localhost защищённым опубликованным сервисом. Настройки и секреты не запрашивались и в Git не сохранены.
