# Состояние Folio CMS

Дата: 2026-10-11. Разрешён только Stage 01; он ещё не принят. Подтверждённое задание `05.txt` заменило Cloudflare Access собственным входом Resend/Turnstile. Stage 00 и прежняя Astro/CLI-архитектура отменены. Работа ведётся в main, без переписывания истории.

## Текущий результат

Адаптивная админка сохранена: обзор, пустые сайты, доступ. Реализован вход по шестизначному email-коду через Resend, серверная проверка Turnstile, атомарные ограничения отправок и попыток, одноразовость, защищённая cookie-сессия на час и выход с отзывом серверного токена. Все ресурсы админки/API требуют сессии; публичны только вход и необходимые ресурсы/API авторизации. Без конфигурации Worker возвращает 503.

Один SQLite Durable Object хранит только состояние авторизации. Коды — HMAC, nonce/сессии/IP — хеши; проверки и изменение состояния выполняются в transactionSync. Workers KV не используется. Migration `v1-auth` / `new_sqlite_classes` включена в Wrangler. Поддержка SQLite DO на Workers Free проверена по официальной документации; оплачиваемые тарифы не включались.

Разрешённый email задаётся через серверный ALLOWED_EMAIL, ключ отправки — RESEND_API_KEY. По уточнению пользователя почта нового аккаунта Resend может отличаться от GitHub; значения email и API-ключ должны относиться к одному аккаунту Resend. При вводе другого email Resend не вызывается. Смена email через админку отложена по выбору пользователя: без своего домена `onboarding@resend.dev` отправляет только владельцу Resend. Новых сайтов, редактора и GitHub API нет.

Документы PRODUCT/ARCHITECTURE/ROADMAP/README/AGENTS/DEPLOY обновлены под собственный вход. Производственная зависимость jose удалена; Miniflare закреплён как devDependency для runtime-тестов (та же версия, которую использует Wrangler). Реальных секретов/адреса владельца в Git нет, тестовые подмены находятся исключительно в tests/.

## Ограничения и следующий результат

Опубликованный Worker и вход владельца пока не проверены. Нет доступа к production-настройкам Cloudflare/Resend; секреты не запрашивались. Нужны действия владельца по DEPLOY.md: Workers Free, Turnstile widget, шесть server settings/secrets, deploy и ручные проверки доставки/входа/выхода/expiry. Отсутствие требования карты именно на аккаунте владельца и реальное потребление Free-квот не подтверждены.

Лимиты не гарантируют доступность при DDoS/исчерпании Free-квот; лимит IP-счётчиков может временно отказать новым IP. На Free требуется следить за usage, платный план не включать автоматически. Resend без домена ограничен одним адресом своего аккаунта.

Следующий результат: внешнее ревью доработки Stage 01 и развёртывание/ручная приёмка владельцем. Stage 02 не разрешён. Точка входа: DEPLOY.md, src/worker.js, src/auth-store.js, tests/runtime.test.js. После публикации кода остановиться для ревью.
