# ADR-0001 — Статическая CMS: предложения Stage 00

Дата исследования: 2026-10-11. Статус: proposed; принятие только после внешнего ревью. Основание: [исследование](../research/STAGE-00.md), [архитектура](../../ARCHITECTURE.md).

## Существенные изменения относительно приложенного пакета

| Изменение | Причина и последствия | Ревью |
|---|---|---|
| Разделены Astro file output и HTTP поведение Pages | Конфигурация сборщика не гарантирует extensionless 200; Stage 04 имеет строгий GET/browser gate | URL требование сохранено |
| Canonical строится из slug, не Astro.url | В file build Astro.url содержит .html | Уточнение реализации |
| Контент предложен в src/content/articles/<slug>/index.md | Нативные локальные images и независимость ID от title; исходный content/articles путь заменён | Подтвердить layout |
| Реестр всех назначенных slug, включая draft и retired | Простые tombstones после удаления не предотвращают случайное переиспользование; CLI берёт max, не count | Подтвердить политику |
| Date фиксируется при назначении ID, YAML date — строка | Иначе редактирование date конфликтует с immutable slug и date/slug consistency | Подтвердить date lock |
| Диапазон даты 2000–2099 | YY не различает столетия; исходник диапазон не определял | Новое ограничение, нужно решение |
| GitHub web использует явный ID и registry в PR | Автоматический ID без CLI/бота не гарантируется, параллельные PR конфликтуют | CLI автоматический, web ручной |
| History validation отделена от snapshot schema | Перестановка slug может пройти проверки одного состояния; нужны базовый Git ref и review | CI в Stage 04 |
| Published отбираются до компиляции медиа | Draft HTML filter не гарантирует отсутствие draft assets в dist | Gate Stage 02/03 |
| Raw HTML отклоняется, MDX отсутствует | Исходник запрещал исполнение, но не задавал enforceable policy | Более строгая authoring policy |
| Pagefind получает явный extensionless URL через Node API | CLI file crawl может сохранить .html; keep_index_url касается index.html | Проверить на Stage 05 |
| Корень сайта допускает завершающий слеш | Строгое правило относится к статьям; project root может редиректиться | Уточнение, не ослабление article gate |
| Backup включает registry, drafts и manifest совместимого кода | Без реестра после restore теряются занятые URL, ZIP контента не содержит toolchain | Gate Stage 07 |
| Черновики защищены с Stage 02 | Stage 06 не может быть первым моментом запрета утечки | Stage 06 — регрессия и UI темы |
| Неопределённости исследования не останавливают Stage 00 | Задача прямо требует подготовить предложения и вопросы; новые этапы остаются закрыты | AGENTS уточнён |

Новых пользовательских функций не добавлено. Локальная CMS/CLI и CI — build-time инструменты; сайта администрирования, server runtime, БД и бот-распределитель отсутствуют.

## Альтернативы и ограничения

Astro + Pagefind сохраняет готовый Markdown pipeline и небольшой search runtime. Самописный генератор уменьшает framework зависимость, но увеличивает собственный код Markdown/assets/search. Directory output проще на многих хостингах, однако `/261011/` не отвечает требованиям. File output с extensionless rewrite на другом статическом хостинге возможен только после отдельного решения о размещении. SPA и 404 fallback нарушают no-JS/direct 200.

Предложен единый slug как ID и append-only резервирование: легче переносить, чем отдельный UUID+slug history. Цена — date нельзя свободно менять и веб-автоматизации нет. Реестр резервов является обычным версионируемым JSON, не внешней БД.

## Нерешённые вопросы

1. Принять диапазон 2000–2099 или нужен исторический/будущий контент иных столетий?
2. Принять фиксированную date при ID и lifetime резерв draft ID? При правке даты какой судьбы требует старый URL?
3. Достаточен ли web шаблон с ручным ID и CLI с автоматическим, без GitHub бота?
4. Принимать raw HTML build error или требуется безопасный поднабор HTML (отдельный анализ)?
5. Какой custom domain и будет ли доступен root deployment для live-test? Пока основной кандидат — project site /folio-cms.
6. Если extensionless gate Pages провалится, менять URL или хостинг? Сейчас ни одно ослабление не принято.
7. Где владелец будет хранить независимые ZIP копии, включая drafts? Репозиторий public: draft скрыт только с сайта, не из GitHub и Git history.

Вопросы не блокируют передачу Stage 00 на ревью; принятие архитектуры и реализация зависят от решений. Никакое предложение не считается новым явным разрешением.
