# Этапы

Каждый этап заканчивается проверками, коммитом в GitHub и остановкой для внешнего ревью. По указанию пользователя от 2026-10-11 результат публикуется прямо в `main`. Следующий этап требует явного одобрения. Старая дорожная карта Stage 00 отменена.

| Этап | Один результат |
|---|---|
| 01 — Первая работающая админка (текущий) | Собственный адаптивный интерфейс; Cloudflare Workers; Cloudflare Access; одноразовый код на разрешённую почту |
| 02 — Создание сайтов | Создание независимых сайтов из админки; автоматическое создание GitHub-репозиториев и настройка Pages; несколько сайтов; ссылки `https://tmksdm.github.io/site-name` |
| 03 — Редактор и публикация | Создание, редактирование, удаление Markdown-статей; изображения; черновики и публикация; автоматические постоянные `/YYMMDD`, `/YYMMDD-2` и далее; GitHub API без ручных коммитов |
| 04 — Публичный сайт | Минималистичный адаптивный дизайн; название и список статей; полнотекстовый поиск; пагинация; светлая/тёмная темы; корректные статьи и изображения |
| 05 — Доводка | Резервное копирование и восстановление; безопасность; телефон и компьютер; исправления и финальная документация |

Этапы 02–05 не разрешены к реализации. На Stage 02 выбирается и реализуется серверная авторизация GitHub API с минимальными правами на создание репозиториев и безопасным хранением credentials.

## Обязательные границы

- `tmksdm/folio-cms` — только движок и админка. Все публичные сайты — в отдельных репозиториях на GitHub Pages, несколько независимых сайтов из одной панели.
- Полноценное повседневное использование с телефона, без ручной работы владельца с GitHub.
- Ссылки на главную — без завершающего слеша; допускается перенаправление GitHub Pages на корень со слешем.
- Статьи — без `.html` и завершающего слеша; доказать реальными тестами до принятия публикации на Stage 03. Если Pages не поддерживает требование, остановиться и согласовать решение.
- Без традиционной БД, обязательных платных сервисов, секретов в браузере и публичных репозиториях. Будущие требования учитывать без преждевременной реализации.
