# ROADMAP.md — Контролируемые этапы

Каждый этап: один ограниченный scope, одна понятная серия коммитов, push и обязательная пауза для внешнего ревью. Нельзя продолжать без явного одобрения заказчика.

| Этап | Результат | Критерий приёмки |
|---|---|---|
| 00 Исследование и дизайн | ADR, документация, план, PoC/доказательства критических предположений | Рассмотрены URL без слеша, схема slug, база пути, search, безопасность, no-db и тестовая стратегия; код CMS пока не писать |
| 01 Каркас | Astro project, scripts, config, lint/typecheck/tests foundation | `npm ci`, проверки и сборка воспроизводимы; нет ненужных зависимостей |
| 02 Статьи/ID/маршруты | Markdown collection, CLI публикации, валидаторы, статические страницы | Уникальность и неизменность slug, невалидные данные блокируют build, отсутствие черновиков, правильные HTML-файлы и ссылки |
| 03 UI/пагинация/медиа | Минималистичный адаптивный UI, 20 заголовков, изображения | Доступность клавиатуры, без JS работают чтение и пагинация, media и пути не сломаны |
| 04 GitHub Pages | Workflows CI/deploy, конфигурация base paths | Live-открытие `/YYMMDD` без суффикса и слеша, reload, цепочки редиректов, production checks |
| 05 Поиск | Pagefind, поле поиска, результаты | Только опубликованные статьи, кириллица, текст заголовка и контента, состояние ошибок, корректный `/repo` |
| 06 Темы/регрессия черновиков | Переключатель темы, проверка уже действующей политики черновиков | Системная тема/ручной выбор/повторный визит; public artifact не содержит drafts; смена статуса публикует |
| 07 Экспорт/восстановление | Команда ZIP + документы и тесты | Экспорт без секретов, восстановление на новом checkout даёт те же статьи и медиа |
| 08 Итоговая проверка | Финальное тестирование и исправления | Smoke, accessibility, build size/performance review, документация точна, никакой необъявленной функциональности |

## Возможные дополнительные стадии
Любые новые требования — отдельный Change Request, оценка рисков, изменение документации и явное согласование. Не добавлять админку, теги, RSS, scheduling без нового решения.

## Зависимости и gates Stage 00

- Stage 01 ограничен [подробным планом](docs/plans/STAGE-01.md); он пока не разрешён.
- Stage 02 отбирает published до media compilation, вводит schema/CLI/реестр и raw HTML policy; Stage 03 проверяет всё дерево assets. Stage 06 не откладывает запрет draft утечек.
- Stage 04 начинается с минимального live URL fixture по [протоколу](docs/research/STAGE-00.md); при провале 200/no-redirect/no-slash запрета следующие этапы заблокированы до решения заказчика.
- Stage 05 получает explicit extensionless Pagefind URLs и base contract; повторяет live переход из search result.
- Stage 07 восстанавливает registry/drafts/media/config вместе с manifest совместимого commit.
- Все ADR Stage 00 остаются предложениями, одобренные этапы отражаются только в PROJECT_STATE после фактического ревью.
